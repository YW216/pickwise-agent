## Bug 修复：build_kb_index.py 报 openai.NotFoundError 404
- 根因：项目无 .env，settings 默认 openai_base_url=api.deepseek.com；DeepSeek 的 OpenAI 兼容接口**不支持 /embeddings**（只支持 chat/completions），embedding 模型 text-embedding-3-small 也是 OpenAI 专属，故 404。
- 修复方案（用户选硅基流动 SiliconFlow）：给 Embedding 独立配置，chat 继续走 DeepSeek。
  - settings.py：新增 `embedding_model`(默认 BAAI/bge-m3) / `embedding_base_url` / `embedding_api_key`（留空回落 openai_*）
  - knowledge.py / build_kb_index.py / test_rag.py：Embedder 改用 `settings.embedding_* or settings.openai_*`
  - .env.example 补充说明；新建 .env（占位 key，待用户填 SiliconFlow key）
- 注意：settings.py 的 model_name 有 pydantic protected_namespace 警告，不影响功能，未处理。

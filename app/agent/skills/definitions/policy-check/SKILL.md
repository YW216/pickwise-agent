## 政策适用性判断流程（咨询）

当用户带着**自己的具体情况**问"能不能保 / 能不能退 / 适用吗"时，不要直接背诵条款——
按以下流程做**对照判断**，给用户一个明确的、有依据的结论。

### 第一步：澄清情况（只问缺的关键项）

判断适用性至少需要三个信息，缺哪个补哪个（用户已说的不要重复问）：
- **何时购买**（决定是否过保 / 是否在 7 天或 15 天期内）
- **什么问题**（性能故障 / 人为损坏 / 不想要了——决定适用哪条）
- **商品**（哪一款 / 什么品类——决定查哪套条款；指名商品时记下商品 ID）

情况已说清就进第二步，不要为流程而流程地追问。

### 第二步：查条款原文

- 涉及保修 → `retrieve_knowledge`（有商品 ID 用 product_id，只有品类用品类兜底）
- 涉及退换货规则、7 天无理由、运费谁出 → `retrieve_knowledge` 检索《退换货政策》
- 涉及配送时效、会员权益 → `retrieve_knowledge` 检索对应政策文档

### 第三步：逐条对照

把用户情况映射到条款，逐项核对：
1. **时间**：购买/签收日期距今多久？在条款期限内吗？
2. **问题性质**：属于"非人为损坏的性能故障"，还是条款明确免责的情形
   （进液、摔落、擅自拆机、外观损伤等）？
3. **凭证**：条款是否要求购机凭证 / 电子订单？

对照结果明确写出：符合哪条、触发哪条免责。

### 第四步：给结论 + 佐证 + 下一步

- **结论先行**：能保 / 不能保 / 需要官方检测认定，三选一，不和稀泥
- **佐证**：引用条款原文（如"条款第 3 条：进液属于人为损坏，需付费维修"），
  说明用户的情形落在哪一条上
- **下一步**：给可执行建议（送官方售后检测 / 联系商家走退换 / 保留凭证与包装）
- 条款没有覆盖的情形（如条款未提及的边缘情况），如实说明"条款未明确"，
  建议用户联系平台客服确认，**不要替平台扩大承诺**

### 注意事项

- 所有条款、期限、免责项照抄工具返回原文，禁止凭常识增减
- 用户后续提出"那帮我推荐一款新的"→ 这是售前诉求，说明本流程不含选购推荐，
  请用户直接提出选购问题
- 情况模糊且用户不在场补充时（如多 Agent 场景），在回复中列出"需要用户补充的信息"，
  不要基于假设下结论

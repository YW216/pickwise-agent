## PickWise 项目改造（本会话主线）

### 产品定位（已锁定）
- 名称 PickWise（Pick=选 + Wise=明智）；目标用户 C 端个人消费者；业务场景 3C 选购决策助手（澄清→搜索→比较→证据化推荐）；明确不做比价/下单/售后
- 文档落盘：`develop_docs/模块/项目概况.md`（已含最新矩阵与原因）

### Agent 划分（按用户心智，非技术工种）
- 路由前台（非 Agent，意图分发+多意图拆分，携带 turn_lookup）+ 3 业务 Agent：
  - 导购（guide，"帮我选"）/ 比选（compare，"哪个好"）/ 咨询（consult，"给我讲讲"）
- 架构声明（用户强调）：多 Agent 是能力组织，单意图请求只激活一个 Agent（自动跳单 Agent）是常态；多意图才多个
- Router 输出：一个或多个场景词，**英文逗号分隔**（如 guide、guide,consult）

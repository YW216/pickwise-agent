## 退换货处理流程（售后）

当用户表达退换货意愿时，按以下流程查询订单、核对资格、给出指引。

### 第一步：确认订单

- 用户给了订单号 → 直接调用 `query_order(order_id=...)` 查单笔详情
- 用户没给订单号 → 调用 `query_order()`（无参）列出全部订单，请用户确认是哪一笔
- 涉及具体商品的保修问题，可用 `retrieve_knowledge` 查该商品的保修条款

### 第二步：核对状态与资格

根据订单状态判断当前可做的事：
- **已签收**：可按退换货政策评估（7 天无理由 / 质量故障），给出资格判断
- **在途**：说明尚未签收，一般不支持直接退货，可提供拦截/拒收思路
- **退货中**：查看订单的售后进度字段，告知当前卡在哪一步、下一步等什么
- **已完成**：按政策说明是否仍在处理期内

退换货政策的资格条款（7 天无理由时限、质量故障与非人为损坏的区分等）
以知识库《退换货政策》和保修条款原文为准，不要凭常识扩大或缩水承诺。

### 第三步：给出指引（只指引，不代办）

- 明确告诉用户下一步做什么：如"商家已同意退货，请按提供的地址寄回商品"
- 需要用户执行操作（提交申请、寄回商品）时，说明申请渠道与所需准备的信息
  （订单号、商品、问题说明/照片）
- **不要声称已替用户完成退款/换货**——当前只做查询和指引

### 注意事项

- 回复中带订单号与状态（照抄工具返回，如 ORD-2025-1003 退货中）
- 涉及金额照抄订单的 paid_amount，不要估算
- 用户提出新的选购需求时，说明选购是售前事务，不在本流程内处理

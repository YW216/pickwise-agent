# 并夕夕 笔记本选购指南

本指南帮助用户按使用场景确定笔记本的关键配置优先级。导购/咨询场景中，用户说"不知道怎么选""帮我看看配置够不够"时，可参照本指南进行需求拆解。

## 一、先定场景，再看配置

买笔记本的第一步不是看参数，而是确认使用场景。不同场景对硬件的敏感度完全不同：

| 使用场景 | 最敏感的配置 | 可以妥协的配置 |
|---------|------------|--------------|
| 日常办公 / 网课 / 网页 | 内存 16GB、重量 | 显卡（核显足够）、屏幕色域 |
| 写代码 / 编程开发 | 内存 16GB 起、CPU 多核 | 显卡（除非 AI/游戏开发）、扬声器 |
| 视频剪辑 / 设计 | CPU 多核、内存 32GB、屏幕色域 | 重量 |
| 大型游戏 / 3A 大作 | 独立显卡、散热、屏幕刷新率 | 重量、续航 |
| 高频移动通勤 | 重量 1.5kg 以内、续航 | 性能释放 |

先问清场景和预算，再进入具体配置推荐，是选购决策的正确顺序。

## 二、处理器（CPU）怎么选

CPU 决定日常响应速度和多任务能力，选购时关注三个指标：

- **核心/线程数**：日常办公 4 核起步；编程编译、视频渲染建议 8 核以上。
- **架构代际**：越新越好，同价位优先新一代（能效比更高）。
- **功耗释放**：同型号 CPU 在不同机身里的性能差距可达 30%，散热好的机器更能发挥 CPU 实力。

判断口诀：轻办公看单核效率，重生产力看多核规模，游戏看单核频率与散热。

## 三、显卡：核显与独显的边界

这是笔记本决策中最容易纠结的一项，边界很清晰：

- **核显（集成显卡）**：共享内存作为显存。适合办公、网页、在线视频、轻度网游（如卡牌、棋牌类）。省电、便宜、机身更轻。
- **独立显卡**：自带显存（常见 4GB / 6GB / 8GB / 12GB）。适合大型游戏、3D 渲染、AI 推理与训练、视频剪辑加速。

显存容量的经验判断：6GB 够多数 1080P 游戏；12GB 面向高画质、高分辨率（2.5K/4K）游戏和 AI 负载。**显存大小直接决定高画质场景下会不会爆显存掉帧。**

注意：大型游戏本通常重量 2kg 上下、续航 6-8 小时，这是性能换来的物理代价，推荐时应主动告知用户。

## 四、内存与硬盘

- **内存**：16GB 是 2024 年后的起步线（浏览器多开 + 办公套件即可占满 8GB）；编程、剪辑、虚拟机建议 32GB。注意部分轻薄本内存板载不可升级，购买前确认。
- **硬盘**：512GB 起步，1TB 是舒适线；剪辑/游戏库大的用户 2TB。固态硬盘（SSD）是标配，无需纠结机械盘。
- **升级空间**：预留空内存槽/硬盘位的机型生命周期更长，可作为同价位之间的加分项。

## 五、屏幕参数速查

屏幕是使用时感知最直接的部件，四个参数按重要性排序：

1. **分辨率**：14 英寸及以上建议 2K（2560×1440）起步；4K 细腻但更耗电。
2. **色域**：办公 P3 或 100% sRGB 足够；设计/剪辑看 100% DCI-P3。
3. **刷新率**：办公 60Hz 够用；游戏 120Hz 起步、165Hz 流畅感明显。
4. **亮度**：室内 300 尼特够用，常在户外用建议 400 尼特以上。

面板类型（OLED / IPS）对观感影响很大，详见《并夕夕 屏幕面板科普》。

## 六、便携三要素

- **重量**：1.5kg 以内算轻薄，2kg 以上是性能本常态；配上充电器实际背负再加 0.3-0.5kg。
- **续航**：官方标称值打七折估算真实续航；核显本普遍优于独显本 2-4 小时。
- **充电器**：支持 PD 快充（Type-C 充电）的机型可共享手机充电头，出行减负明显。

## 七、常见误区提醒

推荐时主动帮用户避开这些坑：

- **只看 CPU 型号不看散热**：同 CPU 性能差距可达 30%。
- **为办公买独显**：多花 2000+ 元换来用不上的性能和更短的续航。
- **忽视接口**：外接显示器、有线键鼠的用户需要 USB-A/HDMI，全 Type-C 机型要额外买转接器。
- **认为内存能随便加**：板载内存机型买小了无法升级，宁可选大。
